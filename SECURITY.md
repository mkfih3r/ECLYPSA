# Security Policy
## Supported Versions
Only the latest release candidate and standard release branches receive active security updates.

| Version | Supported |
| :--- | :--- |
| v0.0.1-alpha | :white_check_mark: |

## Reporting a Vulnerability
**Please do not report security vulnerabilities through public GitHub issues.**
If you discover a potential security flaw in ECLYPSA AI, please follow these steps:
1. Send an email to `security@eclypsa.org` with a detailed description of the vulnerability.
2. Include steps to reproduce, sample proof-of-concept (PoC) code, and affected components.
3. Allow up to **24-48 hours** for our core security team to acknowledge receipt.
## Security Response Lifecycle
- **Response:** Within 48 hours of initial report.
- **Triage:** Within 5 business days to confirm impact and severity.
- **Patch Release:** Target zero-day patches within 14 days of triage.
Thank you for helping keep ECLYPSA AI and its ecosystem secure.
